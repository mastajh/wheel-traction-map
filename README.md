# Wheel Traction Map (Bekker–Wong)

농업 보조 4륜차의 **휠 직경(D) × 폭(b)** 파라미터 공간에서 트랙션을 시각화하는 웹앱.
Bekker–Wong 지반역학 모델 기반, 설치 없이 브라우저에서 바로 실행.

**라이브 데모**: https://mastajh.github.io/wheel-traction-map/

## 해석 모드

### 1. 주행 트랙션 (drive)
- z축: 바퀴당 순견인력 `T = H − Rc` (총견인력 − 압실저항)
- 가이드선: 자력주행 경계(T=0), 목표 견인 달성선, 침하 한계선(z₀/D=0.25)

### 2. 정적 버티기 (hold)
능동 서스펜션으로 차체를 수평 유지하는 차량이 경사 θ의 흙밭에 정지해 있는 상황.
- 바퀴당 수직하중 W = Mg/4 를 지반법선 `N = W·cosθ`, 경사방향 요구전단 `F = W·sinθ`로 분해
- 안전율 `SF = (c·A + N·tanφ) / (W·sinθ)` — SF < 1 이면 실속(미끄러짐)
- 호버에 각 (D, b)의 최대 버티기 각도 θ_max 표시
- 출발(시동) 판단은 주행 모드: 순견인력이 `W·sinθ`를 넘어야 언덕에서 출발 가능
  (정지 한계 θ_hold > 출발 한계 θ_start — 차이는 압실저항 Rc)

## 실제 타이어 규격 비교

데이터시트를 뒤질 필요 없이, 타이어 규격 번호만으로 지도 위에 위치와 성능을 확인.

- **규격 읽는 법**
  - 인치식 `18.4-30` → 폭 18.4 in, 림 30 in. 지름 ≈ (림 + 2 × 0.85 × 폭) × 25.4 mm
    (바이어스 농업용 타이어 단면고/폭 비 ≈ 0.85, 실측 외경 기준 근사)
  - 미터식 `420/85R28` → 폭 420 mm, 편평비 85%, 림 28 in. 지름 = 림 + 2 × 폭 × 편평비
  - ※ 규격식 환산 근사치 — 제조사 데이터시트 외경과 수 cm 차이 가능
- 프리셋 10종(11.2-24 ~ 520/85R38) + 임의 규격 직접 입력
- 체크한 타이어는 2D/3D 지도에 마커로 표시, 목록에는 그 크기의 성능과 판정(목표 달성/미달)이 즉시 계산됨
- "지도 범위 맞추기" 버튼으로 선택 타이어가 모두 보이도록 축 범위 자동 조정

## 트레드 모델

- 유효 마찰각 `δ = m·φ` — 매끈한 바퀴(m=0.7, 흙-고무 마찰) ~ 깊은 러그(m=1.0, 러그 끝 흙-흙 전단)
- 러그 수동저항 부가견인 `H × (1+λ)` — 그루서 추력 1차 근사 (λ: 0~0.4)
- 프리셋: 매끈 강성륜 / 일반 트레드 / 농업용 러그 / 패들 러그
- 한계: Rc는 캐커스 기준(러그 침투 미반영), 단단한 지면에서는 러그 이득 과대평가 가능

## 토양 파라미터 (문헌 값)

J.Y. Wong, *Terramechanics and Off-Road Vehicle Engineering*, 2nd ed. (2009) 파라미터 표 기반:

| 토양 | n | kc (kN/mⁿ⁺¹) | kφ (kN/mⁿ⁺²) | c (kPa) | φ (°) | K (m) | 출처 |
|---|---|---|---|---|---|---|---|
| 양토 (Sandy loam, Michigan) | 0.9 | 52.53 | 1127.97 | 4.83 | 20.0 | 0.025 | Wong (2009) |
| 점토 (Clayey soil) | 0.5 | 13.19 | 692.15 | 4.14 | 13.0 | 0.010 | Wong (2009) |
| 마른 모래 (Dry sand, LLL) | 1.1 | 0.99 | 1528.43 | 1.04 | 28.0 | 0.025 | Wong (2009) |
| 습한 논흙 | 0.7 | 3.00 | 45.00 | 1.50 | 20.0 | 0.020 | 추정치 |

트레드 마찰비 `δ/φ = 0.5~0.9` — Duncan & Mokwa (2001), *J. Geotech. Geoenviron. Eng.*; Fine (2011), *J. Terramechanics*.
러그 계수 λ는 그루서 수동지압 모델(Wong 2009)의 1차 근사에 따른 **가정치**.

## 지반 모델

```
p = (kc/b + kφ)·zⁿ                    (Bekker 압력-침하)
τ = (c + σ·tanδ)·(1 − e^(−j/K))       (Janosi–Hanamoto 전단), j = s·x
z₀ = [ W / (b·k·√D·I(n)) ]^(1/(n+0.5)),  I(n) = √π·Γ(n+1) / (2·Γ(n+1.5))
Rc = b·k·z₀^(n+1)/(n+1)
```

- 가이드선은 D–b 평면 등값선을 log-log 회귀로 `b = α·D^β` 피팅
